# KLE Society's College of Bachelor of Computer Applications (BCA), Gokak
### Modern, Premium College Web Portal

Official, contemporary web portal designed and developed for **K.L.E. Society's College of BCA, Gokak** (Affiliated to Rani Channamma University, Belagavi).

---

## 🎨 Theme & Color Palette
Designed strictly to provide a fresh, modern, and energetic educational presence using an **Orange & White** palette:
- **Primary Vibrant Orange:** `#F97316` / `#EA580C`
- **Deep Accent Orange:** `#C2410C`
- **Soft Orange Light Tint:** `#FFF7ED` / `#FFEDD5`
- **Crisp Pure White:** `#FFFFFF`
- **Complementary Neutral Slate:** `#0F172A` & `#64748B` for high contrast, readable typography.

1. **Top Emergency Announcement & Ticker Bar:**
   - Real-time notification for 2026-27 admissions, official contact helpline (`08332-228650`, `+91 99805 36788`), and official college email (`klebcagokak@gmail.com`).

2. **Responsive Navigation & Mobile Drawer:**
   - Sticky navbar with blur glassmorphism, KLE brand crest, quick links, "Apply Now" action button, and a clean sliding mobile navigation drawer.

   - Dynamic headline highlighting KLE's 108+ years legacy (founded in 1916).
   - High-definition photography composite depicting modern IT students and coding labs.

   - Seamless ticker highlighting news, university results, TECHSPARK IT Fest, and campus placement drives.

   - Dynamic number count-up using `IntersectionObserver`: 108+ Years of KLE, 98% Placement Rate, 120+ Workstations, 300+ KLE Institutions.

   - Story of K.L.E. Society's Saptarshis, accreditation under Rani Channamma University, Belagavi (RCUB), core values, and Principal's message modal.

7. **Interactive BCA NEP 2020 Curriculum Explorer:**
   - Tabbed Semester Navigator (Semester 1 through Semester 6) displaying Course Codes, Course Names, Type (Core/Practical), and University Credits.
   - Value-added certificate tracks: MERN Full Stack, AWS Cloud & DevOps, Python for Data Science & AI.

8. **State-of-the-Art Infrastructure:**
   - High-Tech Computer Labs (Core i7, Gigabit LAN, Dual OS)
   - Digital Library & Knowledge Centre (10,000+ books, IEEE & DELNET)
   - Interactive Smart Classrooms
   - Seminar & Conference Hall (300+ capacity)
   - Student Project & Hackathon Sandbox
   - Sports Complex, Canteen & Hostel Assistance

9. **Placements & Career Pathways:**
   - Top recruiters showcase: TCS, Infosys, Wipro, Capgemini, Cognizant, Accenture.
   - Interactive Alumni Testimonial Carousel with placed package details.

10. **Filterable Photo Gallery & Lightbox:**
    - Categorized gallery: Labs, TECHSPARK Fest, Workshops, Sports & Culture.
    - Full-screen modal Lightbox with zoom and captions.

11. **Live Circulars & Notice Board:**
    - Filter notices by Academic, Examination (RCUB), Placements, or All.
    - Instant search filter with real-time text query.

12. **Online Admission Application Portal 2026-27:**
    - Streamlined eligibility breakdown for PUC/10+2 Science, Commerce, and Arts.

    - Interactive application form with instant validation, automated Registration ID generation (`KLE-BCA-2026-XXXX`), and printable receipt modal.

## 🖥️ How to Preview / Run

You can view the website immediately in any web browser:

1. **Directly in Browser:**
   - Double-click `index.html` or open it with your browser (Chrome, Edge, Firefox).

2. **Using Python's Local HTTP Server:**
   ```powershell
   cd C:\Users\Admin\.gemini\antigravity\scratch\kle-bca-gokak
   python -m http.server 8080
   ```
   Then open `http://localhost:8080` in your web browser.
